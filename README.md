# Vue3 Todo App

使用 Vue3 + TypeScript + Vite 构建的 Todo 管理应用。

## 功能

- ✅ 创建待办任务
- ✅ 标记任务完成
- ✅ 删除待办任务
- ✅ 主题切换（白天/黑夜模式）
- ✅ 数据持久化（localStorage）
- ✅ 单元测试（Vitest）

## 技术栈

- Vue 3 (Composition API)
- TypeScript
- Vite
- Vitest

## 运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行测试
npm test
```

## 项目结构

```
src/
├── components/     # Vue 组件
├── composables/   # Vue Composition API
├── types/         # TypeScript 类型定义
├── utils/         # 工具函数
└── styles/        # 样式文件
```
